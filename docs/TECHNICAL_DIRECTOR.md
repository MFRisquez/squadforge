# Technical Director (v0.4)

TD / DT is **not** a chip. Wildcard stays its own chip.

## Rules

1. Pick a real Premier League club from the **Squad / XI** pitch (**bottom-right corner** badge).
2. You may **start or change** the pick until the deadline of the first GW in that window (including pre-season / GW1 before kickoff).
3. Once that deadline passes, the club is **locked** for **exactly 3 consecutive gameweeks**.
4. After the window ends, pick again.
5. You may not pick the **same club twice in a row** (the next window must be a different club). Older clubs can be reused later.
6. Several managers may back the same club.

## Points per real match that GW

| Result | Points |
|--------|--------|
| Win | **+3** |
| Draw | **+1** |
| Loss | **−1** |

- Double GW: each match counts  
- Blank GW: 0
