# Technical Director (v0.3.2)

TD is **not** a chip. Wildcard stays its own chip.

## Rules

1. You may **start a TD assignment anytime** you do not already have an active window.
2. When you pick a club, it scores for **exactly 3 consecutive gameweeks** starting from the current GW (e.g. pick in GW7 → GW7–9).
3. During that window the club is **locked** (no mid-window swaps — stops chasing easy wins).
4. After the window ends, pick again anytime.
5. You may not pick the **same club as your previous** TD assignment (forces variety).
6. Several managers may back the same club.

## Points per real match that GW

| Result | Points |
|--------|--------|
| Win | **+3** |
| Draw | **+1** |
| Loss | **−1** |

- Double GW: each match counts  
- Blank GW: 0  

## vs Wildcard

| | Technical Director | Wildcard |
|--|--------------------|----------|
| What | Back a real club for 3 GWs | Unlimited free transfers for a rebuild window |
| When | Anytime (if no active TD window) | When you choose to play the chip |
| Uses | Unlimited seasons of windows | 2 per season (2nd from GW20) |
